# Tellable

What the agent may tell anyone about the owner: the owner's own facts, by subject, each with where it came from. Nothing outside this note is told to anyone but the owner, and how much of it reaches whom is decided by `people/Disclosure.md`. The night files a line here for every fact that is the owner's own; the format is in agent-brain `docs/sharing.md`.
