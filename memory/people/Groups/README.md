# Groups

One note per group of people the owner names: `people/Groups/<Name>.md`, frontmatter `kind: group`, with the owner's description quoted and dated, its members as profile links under `## Members`, and a scope note saying who is not in it and why. A group is an audience in `people/Disclosure.md`; a rule for a group covers its current members, so membership changes are disclosure changes and come only from the owner.
